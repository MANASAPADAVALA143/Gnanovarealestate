## What we set up for you

### WhatsApp automation
- Auto-reply when lead sends first message
- Stage-based replies (new lead vs viewing confirmed)
- All messages logged in lead timeline automatically

### Pipeline configuration
We will set up your pipeline stages to match 
how your team works. Default stages:
New → Contacted → Qualified → 
Viewing Scheduled → Viewing Done → 
Negotiation → Booked → Closed

Tell us if you want different stage names.

### Agent accounts
We create login accounts for each agent 
and your manager/admin.
Each agent sees only their own leads.
Manager sees all agents and full pipeline.

### Follow-up task rules
Default rules we configure:
- New lead → 24h follow-up task auto-created
- No response after 48h → task flagged overdue
- Lead replies on WhatsApp → task auto-closed

Tell us if you want different timing.
